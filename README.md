## Get Started

### Prerequisites

- [Rust](https://rust-lang.org) (Latest stable)
- [Node.js](https://nodejs.org) (v18+ or `pnpm`/`bun`)

### Setup & Run

1. **Install dependencies:**

   ```bash
   cd apps/desktop && npm install
   ```

2. **Launch the development loop:**
   ```bash
   npm run tauri dev
   ```
