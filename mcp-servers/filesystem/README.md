### File System Local MCP Server

#### Tools :

- `generate_report` - Generate a professional investigation report in PDF format. Provide case ID, title, status, executive summary, findings and recommendations. Separate multiple findings and recommendations using new lines.
- `unzip_file` - Extracts a local ZIP archive into a target destination directory.
- `create_playbook` - Creates a new Markdown playbook with metadata.
- `image_base64` - Read a JPEG, PNG or WebP image from a file path and return its Base64-encoded contents. The returned Base64 string can be passed directly to classify_image.
- `list_playbooks` - Retrieves a list of all existing Markdown playbooks with their metadata.
- `get_playbook_content` - Retrieves the full Markdown content of a playbook using its ID.
- `read_any_file` - Read any file by converting it to markdown
